# مِرصاد — دليل فرص التعلّم في الكويت

دليل عربي للدورات والورش والمعسكرات المعلنة رسميًا، مع فلترة العمر والتخصص والجهة وطريقة الحضور. لا يعرض بطاقات تأسيسية أو برامج عامة لمجرد ملء الصفحة؛ صفر فرص منشورة يعني دليلًا فارغًا.

## التشغيل

```bash
npm install
npm run dev
```

## قاعدة البيانات والتفعيل

للمشروع القائم الذي لم تُنشأ فيه جداول الدليل: شغّل `node scripts/catalog-setup.mjs` وراجع SQL الناتج ثم طبّقه بموافقة مالك قاعدة البيانات في SQL Editor. يجمع إعداد الدليل داخل معاملة واحدة دون دورات تجريبية أو إنشاء جداول المنصة القديمة. إن كان الدليل موجودًا، طبّق الترحيل الجديد `0007_nullable_age_and_fees.sql` بعد الترحيلات السابقة حتى `0006`. الأسماء الكاملة موجودة في مجلد الترحيلات. الترحيل `0006_complete_official_announcements.sql` يحفظ السجلات القديمة للمراجعة ويخفيها إلى أن تجتاز السياسة الجديدة، ويضيف تخزين الأدلة وحالات القنوات في الخادم.

أضف إلى GitHub Actions Secrets:

- `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY`: اتصال البوت بقاعدة البيانات؛ المفتاح الخدمي لا يصل إلى المتصفح.
- `OPENAI_API_KEY`: استخراج نص الإعلان وصوره ثم مراجعته في طلب مستقل.
- `X_BEARER_TOKEN`: اختياري لتفعيل قراءة المنشورات من X.
- `META_ACCESS_TOKEN` و`INSTAGRAM_BUSINESS_ACCOUNT_ID`: اختياريان لقراءة حسابات إنستغرام المهنية عبر Business Discovery بصلاحيات Meta المناسبة.

متغيرات Actions الاختيارية: `OPENAI_REVIEW_MODEL` (الافتراضي `gpt-5-mini`) و`META_GRAPH_VERSION` (نسخة مدعومة لتطبيق Meta؛ مطلوبة مع ربط إنستغرام). لا تضع أي مفتاح سري في `NEXT_PUBLIC_*` أو في المستودع.

التفعيل الحي يتطلب تطبيق الترحيلات، إعداد الأسرار، رفع المهمة إلى الفرع الافتراضي في GitHub، وتشغيلها بنجاح. نجاح اختبارات محلية بمخرجات وهمية لا يثبت توفر صلاحيات هذه الخدمات.

يمكن تشغيل مهمة GitHub يدويًا بخيار `check_only` لفحص اتصال الخادم بالجداول الثلاثة دون تعديل بيانات أو استهلاك OpenAI. نجاح هذا الفحص ليس نجاحًا للمزامنة أو المراجعة الآلية. عند غياب `OPENAI_API_KEY` تتوقف المزامنة قبل أي تعديل، حتى لا تخفي الدورات بسبب نقص الإعداد. المفتاح الخادمي الحديث `sb_secret_…` مدعوم أيضًا داخل السر `SUPABASE_SERVICE_ROLE_KEY`؛ الاسم للتوافق مع المهمة وليس اشتراطًا لمفتاح JWT قديم.

## كيف تعمل المزامنة؟

المهمة `.github/workflows/sync-opportunities.yml` مجدولة كل 30 دقيقة ويمكن تشغيلها يدويًا. هذا فحص دوري وليس وعدًا بوصول كل إعلان في لحظة نشره؛ توقيت GitHub وحدود واجهات التواصل قد يضيفان تأخيرًا.

1. يقرأ البوت صفحات الجهات الرسمية وروابط التفاصيل ومنشورات القنوات المرتبطة.
2. يستخرج الإعلان من النص والصور الرسمية، ويحفظ اقتباس الدليل لكل مجموعة حقائق.
3. يفحص الوصف والنوع والتخصص والمدة وبداية البرنامج ونهايته والمكان وطريقة الحضور وموعد إغلاق التسجيل ورابطه والصورة. العمر والرسوم غير المنشورين يبقيان `null` ويظهران «غير معلن من الجهة». أي عمر أو رسوم منشورة تحتاج دليلًا؛ الحد الأدنى أو الأعلى المنفرد لا يستلزم تخمين الحد الآخر.
4. يرسل السجل المكتمل إلى مراجعة AI مستقلة مقابل الإعلان الأصلي وصوره. لا تكفي شارة AI لتجاوز فحص الاكتمال.
5. ينشر المطابق والمفتوح تسجيله فقط. نقص الحقائق المطلوبة الأخرى أو التعارض أو تعذّر المراجعة يحجز السجل. غياب العمر أو الرسوم في المصدر وحده لا يمنع النشر، لكن إسقاط معلومة معلنة أو اختلاق قيمة يوقفه.
6. إذا رجعت صفحة تمّت مراجعتها بلا إعلانات، يخفي فرص تلك الصفحة حتى لو كان العدد صفرًا. فشل القراءة يُسجل كفشل، ولا يُعامل كإثبات عدم وجود إعلانات.
7. يعيد قراءة المصدر كل جولة، ويقارن بصمة محتوى الصور نفسها حتى إن بقي رابطها ثابتًا. يفحص صفحة التسجيل الحالية ويعيد مراجعتها عند تغيرها. يعيد الاستخراج عند تغيّر الدليل، وعلى الأقل بعد 24 ساعة حتى مع ثبات البصمة؛ السجلات المحجوزة تُراجع في الجولة التالية. البيانات التي لم يُعد رصدها خلال 24 ساعة تُحجب، والتسجيل المنتهي أو بدء البرنامج يحجبانها فورًا عند قراءة قاعدة البيانات.

يحفظ `learning_source_documents` الأدلة والمراجعات مؤقتًا لتقليل التكلفة، ولا يسمح للمتصفح بقراءتها. تخزّن `learning_sources.channel_status` حالات `ok` و`not_configured` و`unverified_account` و`failed`. لا يعتبر وجود رابط لحساب تواصل دليلًا على أن الربط يعمل.

الجولة محدودة بصفحات التفاصيل وزمن المعالجة لكل جهة، وتتقدم إلى الأقدم فحصًا في الجولات التالية. القراءة تشمل نص المنشور وصوره المتاحة؛ لا تشمل Stories أو الكلام داخل الفيديو أو كل الأرشيف. إعلان لا يتيح تفاصيل كافية يبقى محجوزًا.

## الحسابات والمصادر الرسمية

الحسابات مثبتة من مواقع الجهات بتاريخ 5 سبتمبر 2026، وموجودة في `scripts/official-documents.mjs`:

| الجهة | الحسابات المستخدمة | دليل الرسمية |
| --- | --- | --- |
| KGBC | Instagram: kuwaitgbc | [موقع المجلس](https://www.kuwaitgbc.com/home)، رابط Instagram في التذييل يحوّل للحساب |
| KFAS | Instagram/X: kfasinfo، قناة YouTube المرتبطة | [بوابة المؤسسة](https://apply.kfas.org.kw/) |
| KISR | X: kisrofficial، قناة YouTube المضمّنة | [موقع المعهد](https://www.kisr.edu.kw/en/) |
| SACGC | Instagram/X: sacgc_kw، قناة YouTube المرتبطة | [موقع المركز](https://sacgc.org/en/) |

لم يُفعّل Instagram لـ KISR لأن الموقع الحالي لا يقدّم رابط حساب مباشرًا واضحًا. Facebook وLinkedIn لا يملكان موصل قراءة مفعّلًا في هذا الإصدار. لا تدّعي المنصة متابعة كل شبكات التواصل.

تعمل خلاصات YouTube العامة دون مفتاح. [توثيق Google للخلاصات](https://developers.google.com/youtube/v3/guides/push_notifications). يحتاج X صلاحية قراءة Timeline. [توثيق X](https://docs.x.com/x-api/posts/timelines/integrate). يقتصر ربط إنستغرام على ما تتيحه صلاحيات التطبيق والحسابات المهنية؛ الحساب العام وحده لا يضمن إتاحته عبر API. [توثيق Meta](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api).

## سياسة صحة المعلومات

العمر غير المنشور لا يُستنتج، والرسوم غير المنشورة لا تصبح مجانية؛ يعرض كلاهما «غير معلن من الجهة». عند اختيار عمر معيّن، تُستبعد الفرص بلا حدود عمر معلنة لعدم إثبات الملاءمة. رسوم غير معروفة تأتي بعد الأسعار المعلنة عند ترتيب السعر. بدء الدورة لا يصبح موعد إغلاق التسجيل، ولا توضع صور توليدية على أنها صورة إعلان.

زر التسجيل يفتح رابطًا تابعًا لنطاق الجهة ومثبتًا في الإعلان. لا يُنشئ الموقع نماذج تسجيل. رابط الإعلان الأصلي قد يقود إلى منشور من الحساب الرسمي، مع حفظ دليل ربط الحساب بالجهة.

المراجعة الآلية تقلل الأخطاء ولا تضمن صحة ما نشره المنظم. عند غياب المصدر أو نقص الحقائق المطلوبة عدا العمر والرسوم غير المنشورين تُحجب الفرصة، ويستطيع الزائر الرجوع إلى الإعلان الرسمي قبل التسجيل.

## البناء والتحقق

```bash
npm test
```

يبني الأمر الموقع ونسخة GitHub Pages ويختبر سياسة النشر والاستخراج وحالات النتائج الفارغة وتعذّر الخدمات. فحوص API المحلية تستخدم استجابات اختبار ولا تستهلك مفاتيح فعلية.

`npm run build:github` ينتج النسخة الثابتة في `docs/`. الدفع إلى `main` يشغّل نشر GitHub Pages وفق مهمة المستودع. تُحفظ صور الواجهة القديمة لكن بياناتها التأسيسية لا تُدمج بالدليل الحي.
