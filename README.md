# برنامج استدامة البناء

موقع عربي تعريفي يوثّق أهداف برنامج الاستدامة في البناء، منهجية العمل،
والنتائج القابلة للقياس.

## التشغيل

```bash
npm install
npm run dev
```

## الفحص

```bash
npm test
npm run lint
```

## البنية

- `app/page.tsx`: محتوى الصفحة الرئيسية.
- `app/globals.css`: الهوية البصرية والتجاوب.
- `public/`: الصور وملفات الفهرسة.
- `worker/index.ts`: نقطة تشغيل الموقع.
