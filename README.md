# مِرصاد — دليل فرص التعلّم في الكويت

واجهة عربية ديناميكية لاكتشاف دورات وورش ومعسكرات الكويت، مع البحث والفلترة حسب المجال والعمر والنوع وطريقة الحضور والمكان. تعرض كل بطاقة الوصف، الفئة العمرية، المدة، الرسوم، الجهة المنظمة، رابط المصدر ورابط التسجيل الرسمي.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## Supabase

الواجهة تحاول قراءة جدول `learning_opportunities` من مشروع Supabase الحالي، وتشترك في تحديثاته الفورية. إذا لم يُطبّق المخطط بعد، تعمل تلقائيًا على مجموعة بيانات تأسيسية موثقة داخل المشروع.

1. افتح SQL Editor في Supabase.
2. شغّل `supabase/migrations/0001_civilkuwait_platform.sql` إذا لم يكن مطبقًا مسبقًا.
3. شغّل `supabase/migrations/0002_mirsad_learning_opportunities.sql`.
4. أضف أو حدّث السجلات من لوحة Supabase؛ ستظهر التعديلات في الموقع مباشرة عند تفعيل Realtime.

سياسات RLS تسمح للمتصفح بقراءة السجلات المنشورة فقط. لا توجد سياسة كتابة عامة؛ التحديث المجدول يجب أن يتم من GitHub Actions أو خدمة موثوقة تحتفظ بالمفتاح السري في Secrets.

## GitHub Pages

```bash
npm run build:github
```

يبني الأمر نسخة ثابتة في `docs/`. كما يوجد workflow في `.github/workflows/deploy-pages.yml` ينشر الموقع تلقائيًا عند الدفع إلى فرع `main`.

## التحقق

```bash
npm run typecheck
npm run build
npm run build:github
```

الصور الثلاث داخل `public/courses-*.png` مولدة خصيصًا للواجهة. بيانات النسخة التأسيسية مأخوذة من صفحات جامعة الكويت وخطتها التدريبية 2026/2027، وأي عمر أو موعد غير منشور يظهر بوضوح على أنه غير محدد.
