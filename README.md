# مِرصاد — دليل فرص التعلّم في الكويت

واجهة عربية ديناميكية لاكتشاف دورات وورش ومعسكرات الكويت، مع البحث والفلترة حسب المجال والعمر والنوع وطريقة الحضور والمكان. تعرض كل بطاقة الوصف، الفئة العمرية، المدة، الرسوم، الجهة المنظمة، رابط المصدر ورابط التسجيل الرسمي.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## Supabase

الواجهة تحاول قراءة جدول `learning_opportunities` من مشروع Supabase الحالي، وتشترك في تحديثاته الفورية. إذا لم يُطبّق المخطط بعد، تعمل تلقائيًا على مجموعة بيانات تأسيسية موثقة داخل المشروع.

1. افتح SQL Editor في Supabase.
2. شغّل `supabase/migrations/0001_civilkuwait_platform.sql` إذا لم يكن مطبقًا مسبقًا.
3. شغّل `supabase/migrations/0002_mirsad_learning_opportunities.sql`.
4. شغّل `supabase/migrations/0003_mirsad_automatic_sync.sql` لإضافة موعد إغلاق التسجيل وقاعدة الأرشفة التلقائية.
5. شغّل `supabase/migrations/0004_mirsad_official_registration_urls.sql` لتنظيف روابط النماذج الخارجية وفرض نطاق الجهة الرسمي.
6. شغّل `supabase/migrations/0005_mirsad_ai_review.sql` لإضافة بصمة المحتوى وحالة مراجعة الذكاء الاصطناعي.
7. أضف أو حدّث السجلات من لوحة Supabase؛ ستظهر التعديلات في الموقع مباشرة عند تفعيل Realtime.

سياسات RLS تسمح للمتصفح بقراءة السجلات المنشورة فقط. لا توجد سياسة كتابة عامة؛ التحديث المجدول يجب أن يتم من GitHub Actions أو خدمة موثوقة تحتفظ بالمفتاح السري في Secrets.

## بوت التحديث التلقائي

المهمة `.github/workflows/sync-opportunities.yml` تعمل كل 30 دقيقة، وتستخرج الفرص من البيانات المنظمة `JSON-LD` والروابط التعليمية والجداول المؤرخة في المصادر الرسمية. المصادر الأساسية المضافة حاليًا هي **KGBC وKFAS وKISR وSACGC**، إلى جانب صفحات جامعة الكويت التأسيسية. تضيف المهمة السجلات الجديدة إلى Supabase، وتخفي أي سجل تجاوز `registration_ends_at` (أو `ends_at` عند غياب موعد مستقل للتسجيل). فشل مصدر واحد لا يمنع بقية المصادر من التحديث.

بعد الاستخراج، يراجع الذكاء الاصطناعي السجلات الجديدة أو التي تغيّرت بصمتها فقط مقابل النص المنسوخ من صفحة الجهة الرسمية. لا يُسمح له بإكمال أو تصحيح أو اختراع العمر والمواعيد والمكان والروابط. النتيجة المطابقة تحمل حالة `verified`، وأي تعارض أو نقص في الدليل ينقل السجل إلى `needs_review` ويمنع نشره تلقائيًا. تعذّر OpenAI لا يوقف جمع المصادر؛ تُسجّل الحالة `unavailable`، يُحجز السجل المتغيّر عن النشر، وتُعاد المراجعة في الجولة التالية.

كل رابط تسجيل يمرّ على سياسة نطاقات موثوقة: `kuwaitgbc.com` و`kfas.org.kw` و`kisr.edu.kw` و`sacgc.org` و`ku.edu.kw`. إذا نشرت الجهة زرًا يقود إلى Microsoft Forms أو Google Forms أو Zoho، يحفظ البوت بدلًا منه صفحة الفرصة الرسمية لدى الجهة؛ والواجهة تطبق الحماية نفسها قبل فتح الرابط.

أضف الأسرار التالية في **GitHub → Settings → Secrets and variables → Actions**:

- `SUPABASE_URL`: رابط مشروع Supabase.
- `SUPABASE_SERVICE_ROLE_KEY`: مفتاح الخادم؛ لا يوضع أبدًا في متغيرات `NEXT_PUBLIC_*` أو داخل المستودع.
- `OPENAI_API_KEY`: مفتاح مراجعة السجلات في الخادم؛ لا يصل إلى المتصفح أو Supabase.

ويمكن اختياريًا إضافة متغير Actions باسم `OPENAI_REVIEW_MODEL`. القيمة الافتراضية هي `gpt-5-mini`. مفتاح OpenAI غير الموجود لا يعطّل الجمع، لكنه يحجز السجلات الجديدة والمتغيّرة عن النشر حتى تنجح مراجعة لاحقة.

يمكن تشغيل البوت يدويًا من تبويب Actions أو محليًا في بيئة آمنة:

```bash
npm run sync:opportunities
```

إضافة جهة جديدة تتم بإضافة رابطها الرسمي إلى `defaultSources` في `scripts/sync-opportunities.mjs`. عندما تنشر الجهة موعد انتهاء التسجيل في بياناتها المنظمة، يلتقطه البوت تلقائيًا؛ وإذا لم تنشره، تبقى الحالة «تحقّق من التوفر» بدل اختراع تاريخ.

## سياسة صحة المعلومات

- لا يُسجل عمر رقمي إلا إذا نشرته الجهة رسميًا؛ وإلا يظهر «لم يحدده المنظم».
- تحتفظ كل فرصة برابط المصدر وتاريخ آخر مراجعة ظاهر للمستخدم.
- يراجع الذكاء الاصطناعي الحقائق المستخرجة مقابل النص الرسمي، ولا ينشر السجل المختلف أو غير المدعوم.
- تُخفى الفرص ذات موعد التسجيل المنتهي، وتُغلق الفرص التي تختفي من مصدر نجح البوت في قراءته كاملًا.
- حالة «تحقّق من التوفر» تعني أن الجهة نشرت البرنامج دون موعد تسجيل نهائي يمكن الاعتماد عليه.

## GitHub Pages

```bash
npm run build:github
```

يبني الأمر نسخة ثابتة في `docs/`. كما يوجد workflow في `.github/workflows/deploy-pages.yml` ينشر الموقع تلقائيًا عند الدفع إلى فرع `main`.

## التحقق

```bash
npm run typecheck
npm run build
npm run build:github
```

الصور الثلاث داخل `public/courses-*.png` مولدة خصيصًا للواجهة. بيانات النسخة التأسيسية مأخوذة من صفحات جامعة الكويت وخطتها التدريبية 2026/2027، وأي عمر أو موعد غير منشور يظهر بوضوح على أنه غير محدد.
