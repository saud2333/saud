# CivilKuwait

منصة ويب عربية/إنجليزية للهندسة المدنية في الكويت تشمل الإنشاءات، المياه، الطرق والبنية التحتية، الأدلة، سوق المواد، BOQ، حاسبات هندسية، مساحات مشاريع، ولوحة إدارة.

## التشغيل

```bash
npm install
npm run dev
```

## الفحص وقاعدة البيانات

```bash
npm run typecheck
npm run build
npm run db:generate
```

راجع [ARCHITECTURE.md](./ARCHITECTURE.md) لتفاصيل الصفحات، واجهات API، قاعدة البيانات، مصادر البيانات، الأمان، ومعمارية الذكاء الاصطناعي.

البيانات الظاهرة حاليًا تجريبية وموسومة بوضوح. الأسعار والمشاريع والملفات المهنية الحقيقية لا تظهر قبل ربط مصدر موثوق ومراجعتها.
